Спряжение неправильных глаголов I спряжения. Часть 4.

Глаголы с двойным и тройным чередованием гласных и согласных

В этой группе неправильнвх глаголов I спряжения сгруппированы глаголы, формы которых содержат сразу несколько общих признаков чередования гласных и согласных наложенных друг на друга одновремено.

Двойное чередование

1) чередование гласной a->o для всех лиц в в Tagadne;
2) чередование согласной к->с, g->dz только для 2 л.ед,ч. в Tagadne 
Nenotieksme   Tagadne,1p.vsk.   Pagatne,1p.vsk.
   rakt        - roku(c)*     - raku          - рыть, копать
   lakt        - loku(c)*     - laku          - лакать
   plakt       - ploku(c)*    - plaku         - опускаться
   smakt       - smoku(c)*    - smaku         - опускаться
   zagt        - zodu(dz)*    - zagu          - красть
Ппимечание: * - обозначено второе чередование согласных к->с, g->dz только для 2 л.ед,ч. в Tagadne

Тройное чередование

1) глаголы c чередованием согласной s->d, s->t для всех лиц, чисел и времен, кроме Tagadne 2л.ед.ч.
2) гласной a->o для всех лиц в в Tagadne;
3) согласного s->bi только для 2л.ед.ч. Tagadne.
  
Nenotieksme   Tagadne,1p.vsk.   Pagatne,1p.vsk. Nākotne,1p.vsk.
   rast        - rodu(i)         - radu          - radīšu           - обрести
   pierast     - pierodu(i)      - pieradu       - pieradīšu        - падать
   prast       - protu(i)        - pratu         - pratīšu          - уметь, знать

Глаголы c чередованием согласной s->t в Tagadne и Pagātne во всех лицах;
с удлинением коротких гласных i, u в длинные в Tagadne; добавлением окончания i в Tagadne 2л.ел.ч.

(Три правила одновременно!)
